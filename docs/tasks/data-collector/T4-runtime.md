# T4 — 完整采集运行时

- 前置：T3 已提交。
- 目标：独立 C++ 进程连通 CTP → latest state → 定时 snapshot → SQLite。
- 范围：SPI 生命周期、SDK 自动重连后的重登录与重订阅、登录重试/超时、分批订阅与逐合约状态；主循环写入、健康输出、signal/定时退出尾部 flush、失败非零退出。
- 非目标：不提供 tick 回补或无限缓存保证，不实现自动合约发现。
- 验证：fake CTP API 驱动真实 SPI 的连接/重连/本地请求拒绝/响应错误/超时/无行情，验证恢复与状态；端到端回调到 SQLite；停机释放顺序与尾部提交；持久化失败传播。
- 完成记录：Debug 构建与全部四项 CTest 通过。真实 SDK 接口的 C++ fake 验证本地登录/订阅拒绝重试、响应错误、登录/订阅超时、断线重连与订阅恢复、无行情状态、callback 异常隔离；真实主循环经 SPI 进入 Daily SQLite，验证最后 callback 在 Release 前复制、Release 后尾部提交和正常 run 结束标记；注入 SQLite 打开失败确认异常传播与 SDK 释放。连接超时限制 1–3600 秒以避免时间计算溢出。
