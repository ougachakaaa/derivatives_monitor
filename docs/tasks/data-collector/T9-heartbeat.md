# T9 — Collector 应用心跳

- 目标：在不引入 Python 依赖的前提下，让外部只读观察者识别 Collector 存活及采集状态。
- 范围：原子 JSON 状态发布，每 2 秒一次，启动/停止/失败标记；诊断失败不能终止采集；只在数据目录锁持有期间写入；容器心跳检查脚本。
- 验证：正常采样同时更新状态、休市无行情也更新心跳、正常退出/异常状态、旧文件过期、原子替换失败处理；已有 CTest 回归。
- 完成记录：新增 heartbeat 状态原子发布与主循环集成；Release 六项 CTest 通过，包含无行情的运行状态、停止/失败标记、发布失败不抛出及实际 runtime 退出路径；shell 心跳检查通过缺失/活跃无报价/过期/停止场景和 ShellCheck。
