# T2 — 内存状态与 snapshot

- 前置：T1 已提交。
- 目标：真实 SDK 结构可以转换为有明确日分区和采样语义的 snapshot。
- 范围：线程安全 latest state、原始事实字段映射、接收/物化时间、序号、两日有界状态与拒收统计。
- 非目标：不写库、不连接网络、不做分析。
- 验证：窗口内合并、无更新不重复、最后一条更新、深拷贝、NULL 规则；合法/非法交易日、ActionDay 不参与分区、日切及旧日乱序、第三日容量保护；并发接收和物化。
- 完成记录：Debug 构建与 config/state 两项 CTest 通过。验证 46 个非保留源字段、SDK 缓冲区深拷贝、窗口合并、空窗口、两日隔离、第三日未物化保护、非法/过旧日拒收、NULL 数值判断及 10000 次并发更新。
