# Futures Coverage Specification

## 产品全集

必须覆盖 CFFEX 股指期货：`IH`、`IF`、`IC`、`IM`。

## Probe 验收

对每个产品分别确认并留证：

- 当前有效合约能否由来源动态发现，而非只请求预先知道的合约；
- 至少对当前月和下一月合约记录来源使用的 contract code；
- snapshot quote 能否获取，并保存请求实际返回的完整内容；
- 从实际响应中能够识别哪些行情语义，以及有哪些无法确定或缺失的信息；
- 1 分钟数据能否获取并留下实际响应；如来源提供其他粒度，记录实测能力；
- 缺失合约或无法确认的语义等限制。

不得把 Reference 示例中的 `2609` 硬编码为当前合约，也不得用历史字段或结构假设解释尚未保存和检查的响应。
