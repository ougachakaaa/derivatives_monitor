## Probe 验收

对每个指数分别确认并留证：

- 是否可以由来源发现或按 identifier 获取；
- 来源实际使用的 symbol / instrument identifier；
- snapshot 行情是否可以获取，并保存请求实际返回的完整内容；
- 从实际响应中能够识别哪些行情语义，以及有哪些无法确定或缺失的信息；
- 若后续需求确实依赖分钟数据，验证其可用性并保存实际响应；否则明确记为 `NOT_TESTED`，不影响 snapshot coverage 状态。

7 个指数必须各有状态和证据路径，不能只用一次批量成功概括全部标的。
