## Probe 验收

对每个指数分别确认并留证：

- 是否可以由来源发现或按 identifier 获取；
- 来源实际使用的 symbol / instrument identifier；
- 原始响应的编码、单条/批量结构、字段顺序或字段名；
- 行情值、来源时间（若有）、空值和缺失值的真实表达；
- 若后续需求确实依赖分钟数据，分钟 endpoint 的可用性与原始结构；否则明确记为 `NOT_TESTED`，不影响 snapshot coverage 状态。

7 个指数必须各有状态和证据路径，不能只用一次批量成功概括全部标的。
