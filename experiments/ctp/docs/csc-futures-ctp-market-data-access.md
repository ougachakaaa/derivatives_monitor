# 中信建投期货 CTP 行情接入信息

## 文档用途

本文整理自《中信建投期货 CTP 行情 API 咨询问题清单——MVP 精简版》，用于记录当前 Linux 行情客户端的券商接入参数、能力边界和待确认事项。

这是一份接入快照，不是券商服务承诺。前置地址、权限、费用和限制都可能变更，生产使用前应向中信建投期货再次确认。

## 接入参数

| 项目 | 值 |
|---|---|
| CTP BrokerID | `9080` |
| 行情协议 | TCP |
| 行情端口 | `42213` |
| 接入类型 | 支持穿透式监管的 CTP 主席接入 |

行情前置节点：

| 线路 | 城市 | FrontMdAddr |
|---|---|---|
| 电信 | 重庆 | `tcp://61.186.254.135:42213` |
| 电信 | 上海 | `tcp://101.230.125.167:42213` |
| 电信 | 上海 | `tcp://101.230.125.168:42213` |
| 联通 | 上海 | `tcp://140.207.150.241:42213` |
| 联通 | 重庆 | `tcp://113.204.105.118:42213` |
| 联通 | 北京 | `tcp://202.130.235.165:42213` |

当前示例配置使用重庆电信节点：

```ini
[config]
FrontMdAddr=tcp://61.186.254.135:42213
BrokerID=9080
```

Front 应根据本机网络选择；如首选节点不可达，可依次测试同运营商的其他节点。

## 已回复的行情能力

| 主题 | 券商回复 | 对当前项目的含义 |
|---|---|---|
| 中金所品种覆盖 | “中金所推送的行情都可以收取” | 可用于 IF、IH、IC、IM 股指期货及 IO、HO、MO 股指期权，以交易所实际上市和推送的合约为准。 |
| 行情粒度 | 刷新频率每秒 2 次 | 按约 500 ms 频率接收 CTP 行情快照，不应将它表述为逐笔成交数据。 |
| 全量期货和期权订阅 | 可以，回复为“无限制” | 可按明确合约列表订阅全部目标合约；仍应在正式上线前确认实际订阅数量和连接数限额。 |
| 现货指数 | 无 | CTP 行情前置不提供沪深 300、上证 50、中证 500、中证 1000 等现货指数实时行情。 |
| 资金门槛、费用、固定 IP 等条件 | 对合并问题回复“无” | 暂按无额外条件记录，但这一答复未逐项确认，需在开通时复核。 |

## MVP 数据目标与边界

目标合约类型：

- 股指期货：IF、IH、IC、IM。
- 股指期权：IO、HO、MO。
- 保存 CTP 行情快照，再由本地程序生成 1 分钟数据。

实现时需注意：

- Market Data API 需要传入精确的合约代码；“可订阅全部合约”不等于空订阅即自动获取全市场。
- 完整期权链依赖一份及时更新的上市合约清单；当前 Linux 行情客户端不负责查询或发现合约。
- 基差计算需要期货行情与现货指数。由于该 CTP 前置不提供现货指数，现货数据必须由另外的合规数据源提供。
- IV 计算除期权行情外，还需要标的价格、行权价、到期时间、利率等输入；不能仅依赖期权快照。
- 行情数据仅用于个人盯盘和研究，不对外提供或转发。

## 开通前待确认

原咨询记录没有对以下事项给出足够明确的逐项答复：

1. 个人客户是否需要单独申请行情 API 权限，以及仅使用行情时的开通流程。
2. 行情登录是否必须使用 `UserID` 和 `Password`，以及账号并发登录数限制。
3. “无限制”的具体范围：单连接订阅数、连接数、登录数和订阅请求频率。
4. 费用、最低权益、固定 IP、IP 白名单和行情使用范围是否均无额外要求。
5. 前置节点的有效期、建议主备顺序，以及维护或变更通知渠道。
6. 获取当前全部上市合约和完整期权链的官方方式。

## 后续使用 Trader API

如后续增加程序化或自动化交易，券商回复需要：

1. 提交外接系统管理表。
2. 进行穿透式监管测试。
3. 涉及程序化交易时，完成程序化交易功能测试。

当前工程只使用 Market Data API，不包含 Trader API，也不发送交易请求。
